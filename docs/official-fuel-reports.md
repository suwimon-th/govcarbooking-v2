# รายงานน้ำมันตามแบบราชการ

เปิดเมนูรายงานน้ำมัน แล้วเลือก “รายงานน้ำมันตามแบบราชการ” (`/admin/reports/fuel/official`) ใช้สิทธิ์ `reports.fuel` เช่นเดียวกับรายงานน้ำมันเดิม

รองรับบันทึกข้อความ, รับ–ใช้–คงเหลือสองงวด, R03 จำแนกประเภททรัพย์สินและชนิดน้ำมัน, บัญชียานพาหนะรายปีและรายเดือน, บัญชีเครื่องจักรและเครื่องทุ่นแรงรายปีและรายเดือน พร้อมพิมพ์หรือบันทึก PDF จากหน้าพิมพ์ของเบราว์เซอร์

## การกรอกและบันทึก

1. เลือกปีงบประมาณ พ.ศ. และเดือน (ตุลาคมปีก่อนถึงกันยายนปีที่เลือก)
2. กรอกข้อมูลหน่วยงาน ผู้จัดทำ และผู้รายงาน ชื่อบุคคลต้องกรอกตามผู้ลงนามปัจจุบัน
3. เปิดข้อมูลประกอบรายเดือน ตรวจยอดได้รับที่ดึงจากใบเบิกสถานะ COMPLETED ตามวันที่เบิก และตรวจยอดจริง (`actual_amount`) โควตา (`system_quota`) และเลขไมล์ที่ดึงอัตโนมัติ แล้วกรอกเฉพาะข้อมูลที่ยังไม่มีให้ครบ
4. ใบเบิกที่ระบุเครื่องเดียวแยกดีเซล/เบนซินจากข้อความโควตาอัตโนมัติ ส่วนใบเบิกที่มีหลายหมายเลขต้องจัดสรรปริมาณด้วยตนเอง ดูรายการใบเบิกที่ต้องจัดสรร แล้วกรอกยอดแยกเครื่อง สามารถเพิ่มแถวเพื่อแยกชนิดน้ำมันได้
5. บันทึกข้อมูลเดือนนี้ แล้วเลือกแบบรายงานและพิมพ์

งวดแรกวันที่ 1–15 งวดหลังวันที่ 16–สิ้นเดือน ยอดได้รับอ้างอิงโควตาในใบเบิก (ใช้ปริมาณจริงเมื่อไม่มีโควตา) ยอดใช้จริงอ้างอิง actual_amount ตามรายงานเดิม ถ้ายังไม่มีปริมาณจริงจะแสดง “—” ยอดคงเหลือคำนวณจากต้นงวด + ได้รับ − ใช้ ช่องว่างคือไม่มีข้อมูลและแสดง “—” ต้องระบุ 0 เมื่อยืนยันว่าไม่มีการใช้จริง กม./ลิตรคำนวณจากระยะทาง / ลิตรใช้จริง เมื่อไม่มีการใช้จะแสดง “—”

ข้อมูลตั้งต้นเดือนถัดไปใช้ข้อมูลครุภัณฑ์ โควตา เลขไมล์ปลาย และยอดคงเหลือจากเดือนก่อนที่บันทึกไว้ ต้องตรวจสอบหลังแก้ไขรายงานย้อนหลัง: เดือนที่บันทึกแล้วไม่ถูกแก้ตามเดือนก่อนโดยอัตโนมัติ

ข้อมูลตั้งต้นทั้งปีดึงจากใบเบิกและเลขไมล์ โดยเทียบทะเบียนหลังตัดช่องว่าง ข้อมูลที่กรอกและบันทึกไว้จะใช้แทนข้อมูลตั้งต้นเมื่อมีค่า บัญชีรายปีรวมเฉพาะเดือนที่มีข้อมูลและแสดงจำนวนเดือนที่ยังไม่ครบ โควตารายปีรวมโควตาที่บันทึกในแต่ละเดือน เลขไมล์ต้นปีใช้เดือนตุลาคมและปลายปีใช้เดือนกันยายน อัตราสิ้นเปลืองรวมคำนวณจากผลรวมระยะทางรายเดือน / ผลรวมลิตรใช้จริง

## ฐานข้อมูลและการตรวจสอบ

ตาราง `official_fuel_reports` เก็บรายงานแยกปีงบประมาณและเดือน เปิด RLS และอนุญาตให้เซิร์ฟเวอร์ใช้ service role หลังตรวจสิทธิ์แล้วเท่านั้น สำหรับฐานข้อมูลใหม่ รัน `scripts/create_official_fuel_reports.sql` ก่อนใช้งาน

ทดสอบสูตรและสิทธิ์: `node --test tests/official-fuel.test.cjs` ตรวจ TypeScript: `npx tsc --noEmit` และ build: `npm run build`

## ชุดรายงานตามตัวอย่าง Excel

เลือกแบบรายงานแต่ละรายการได้โดยตรงจาก Dropdown: บัญชีเครื่องจักรรายปี บัญชีเครื่องจักรรายเดือน บัญชียานพาหนะรายเดือน (แยกทะเบียน) วิธีคิดค่าเฉลี่ย และบัญชียานพาหนะรายปี (รายงานรวมตามตัวอย่าง Excel) ก่อนเลือก Excel / PDF แล้วดาวน์โหลด จำนวนชีตรถขึ้นกับข้อมูลในปีที่เลือก ไม่คัดลอกชีตประวัติหรือยอดจากไฟล์ตัวอย่าง

แม่แบบหัวตาราง การรวมเซลล์ และความกว้างคอลัมน์ถอดจากไฟล์ตัวอย่างไว้ใน `lib/report-templates/fuel-layout.json` โดยไม่มีข้อมูลรายการเดิม รายงาน Excel ประเภทบัญชีรายปี/รายเดือนใช้แม่แบบนี้ด้วย มีตัวเลขจริง สูตรค่าเฉลี่ยรายเดือนพร้อมค่าคำนวณเริ่มต้น และตั้งค่าพิมพ์ A4 แนวนอน สูตรป้องกันการหารด้วยศูนย์ ยอดทั้งปีแสดง “—” หากข้อมูลครบ 12 เดือนไม่เพียงพอ

ตรวจชุดรายงานเพิ่มเติม: `node --test tests/fuel-workbook.test.cjs`
