# Automated TESTER flow

รันจากโฟลเดอร์โปรเจกต์:

```sh
npm run test:tester-flow
```

ทดสอบ route handlers จริงร่วมกับ proxy, signed session และ Supabase SDK โดยจำลองการตอบกลับฐานข้อมูลในหน่วยความจำ ไม่อ่าน `.env.local` และไม่ต้องเปิด dev server บัญชี TESTER เป็น fixture ที่สร้างใหม่ทุกกรณี ไม่ใช่บัญชีบน Supabase จริง

ครอบคลุม:
- ล็อกอิน TESTER และเข้าหน้าขอใช้รถ/คำขอของฉัน/เบิกน้ำมัน
- ขอใช้รถสำเร็จ เลข TEST-xxxxxx สถานะ REQUESTED และข้อมูลเวลา/ปลายทาง/ผู้โดยสาร
- อ่านคำขอของตนเอง โดยไม่รวมคำขอของผู้ใช้อื่น
- ขอเบิกน้ำมันสำเร็จ ข้อมูลตรงกับแบบฟอร์มและสถานะ PENDING
- รหัสผ่านผิด ไม่มี session ถูกถอนสิทธิ์ขอใช้รถ กรอกข้อมูลไม่ครบ รถจองซ้ำ และฐานข้อมูลบันทึกไม่ได้

อีเมลถูกเก็บในตัวแปรทดสอบ ส่วน LINE ถูกแทนที่ด้วย stub และ fetch ทั้งหมดถูกจำกัดไว้ที่โดเมนจำลอง ไม่มีการส่งแจ้งเตือนหรือเขียนข้อมูลจริง ข้อความ EMAIL/DB Error ในผลรันเป็น log ของ handler ที่ใช้ mock รวมถึงกรณีจำลองฐานข้อมูลล้มเหลว

ข้อจำกัด: เป็น API integration flow ไม่ได้คลิก/กรอกฟอร์มใน browser และไม่ได้ยืนยัน schema, RLS หรือการเชื่อมต่อ Supabase จริง หน้าเบิกน้ำมันและ API POST ปัจจุบันเป็นสาธารณะ การทดสอบขณะล็อกอิน TESTER จึงไม่ได้หมายความว่า endpoint นี้จำกัดเฉพาะบทบาท TESTER
